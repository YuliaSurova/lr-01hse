## Назначение

В программе принемаеться на вход длинны двух массивов n и m,вместимостью от 1 до 20.Для первого массива А(размером n) данные пользователь вводит самостоятельно с клавиатуры.Для второго массива B(размером m) элементы вычисляются по заданой формуле.Пользователь вводит только парметры a, x, h необходимые для построенния B.После, из массива B удаляются все отрицательные элементы строго левее первого максимума.После в массиве А  последний элемент копируется в конец.В конце, в массиве А все элементы по модулю меньше 1 заменяються на 1.

## Ограничения

- Допустимый диапазон входного значения длин массивов: натуральные числа от 1 до 20.
- Емкость массивов: 20
- Случаи, при которых программа сообщает об ошибке:
    1.Неверный ввод длины массива(превышвющий заданый или меньше 0): ошибка ввода.
    2.Неверный ввод элементов массива A: ошибка ввода.
    3.Неверный ввод длинны массива B(превышвющий заданый или меньше 0): ошибка ввода.
    4.Невернный ввод параметров (a, x ,h) для создания массива В: ошибка ввода.
    5.Пустой массив В: массив пуст.
    6.Переполение массива А после вставки: массив переполнен.

## Формат ввода и вывода

Ввод:

1. n - длинна массива А(целое число)
2. n элементов массива А(вещественные числа)
3. m - длинна массива B(целое число)
4. a, x ,h - параметры для построения массива B(вещественные числа)
Вывод: 
```bash
    1.Массив А длиной n(вещественные числа с тремя знаками после запятой).
        А: 0.345 -4.322 6.000
    2.Массив В длиной m(вещественные числа с тремя знаками после запятой).
        B: -3.333 6.767 1.000 9.543
    3.Массив В после удаления элементов(вещественные числа с тремя знаками после запятой).
        B: 6.767 1.000 9.543
    4.Массив А после вставки длинной n+1(вещественные числа с тремя знаками после запятой).
        А: 0.345 -4.322 6.000 6.000
    5.Массив А после замены числел, которые по модулю меньше 1, на единицу(вещественные числа с тремя знаками после запятой).
        А: 1.000 -4.322 6.000 6.000
```
Сообщения:
```bash
ошибка ввода - неверный ввод длины массива (n<1 или n>20),неверные значения массивов.
массив пуст - после удаления в массиве В,массив остался пустой.(недостижимо из за условий задачи)
массив переполнен - В массиве А ужн имееться 20 элементов и дублирование элемента приведет к переполнению.
```

Пример ввода:

```text
4
0.03 6.5 -0.3 7.8    
3
3.33 5 7.7
```

Вывод для этого примера:

```text
A:
0.030 6.500 -0.300 7.800 
B:
-0.388 -1.234 0.009 
B после удаления:
0.009 
A после вставки:
0.030 6.500 -0.300 7.800 7.800 
A после изменения:
1.000 6.500 1.000 7.800 7.800 
```
